# Design Vocabulary

## Backgrounds
- Gradient meshes: multi-stop radial/linear gradients
- CSS grain/noise: SVG noise overlays for texture
- Geometric shapes: absolute-positioned blurred circles, rotated rectangles
- Dot grids: CSS-generated repeating patterns
- Ambient glows: large blurred coloured elements

## Animations
- Stagger reveal: children animate in sequence
- Scroll-triggered fade: animate on viewport entry
- Parallax layers: different scroll speeds
- Hover transforms: lift, scale, shift on hover
- Text reveal: word-by-word or letter-by-letter
- Counter animation: numbers count up on entry
- Page transitions: fade/slide between routes

## Typography
- Display fonts: large expressive typefaces for heroes
- Serif/sans pairing: editorial feel
- Variable font weight: use ranges for emphasis
- Letter-spacing: tight on large headings, loose on small caps
- Gradient text: gradient-clipped headings
- Monospace accents: for dates, tags, code

## Layered UI
- Overlapping cards: components overlap sections
- Floating elements: absolutely positioned decorations
- Glassmorphism: backdrop-blur + semi-transparent
- Elevated cards: deep shadows with hover depth
- Sticky elements: parallax during scroll
- Bento grid: asymmetric layouts

## Mood Patterns

| Mood | Background | Typography | Animation | Colour |
|---|---|---|---|---|
| Premium/dark | Gradient mesh, glows | Tight-tracked sans | Slow reveals | Near-black + vivid |
| Warm/editorial | Cream texture, grain | Serif + sans | Gentle fades | Earth tones |
| Bold/creative | Shapes, gradients | Oversized display | Stagger lifts | High contrast |
| Minimal/clean | White, shadows | Medium-weight sans | Fast transitions | Monochrome |
| Glassmorphic | Blurred gradients | Light-weight sans | Slide-ins | Pastel accent |
| Technical | Dot grid, dark | Geometric sans | Typing, counters | Dark + green/amber |
