# AI Harnesses

A repo to keep track of changes to installed Agents, Skills and configurations across 
a variety of AI Tools, e.g. Claude, Copilot, and others.

## Motivation

I was having trouble transferring skills and agents between Copilot (where I initially 
started using LLMs), and Claude Code (where I realized the real power was).

Using a git repository with a branch for each tool was a way to easily translate these 
skills between the tools, as well as a way to track changes in configuration as I discovered
more about the tools themselves.
